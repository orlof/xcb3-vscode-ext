# Optional: debugger

**Retro Debugger** lets you step through the generated machine code with a live view of memory, sprites and the VIC chip.

1. Download it from <https://github.com/slajerek/RetroDebugger/releases>.
2. Run **XC=BASIC: Setup** again and pick it in the second step.
3. Press **F5** in a `.bas` file to compile and open the program in the debugger.

Extra command line arguments for the debugger or the emulator can be added in the settings `xcbasic3.debuggerArgs` and `xcbasic3.emulatorArgs`.
